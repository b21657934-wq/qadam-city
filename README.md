# Qadam City — AI book v2

Interactive AI book for **AIF1303 AI Fundamentals**, Qairu University. Team 11: Yuldashov Bilal, Tashmetov Shakhrukh.

Qadam the builder robot grows a smart city on a snowy steppe: every AI topic (weeks 1–10) adds a new city system.

- `src/` — source (three.js scene, UI, missions, EN/RU/KZ text)
- `dist/index.html` — the single self-contained file that is deployed
- Build: `npm install && node tools/build.mjs`
